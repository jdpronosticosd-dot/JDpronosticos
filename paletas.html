Elige tu paleta

Diez propuestas para una web de apuestas deportivas, aplicadas a la misma tarjeta de pick. Toca cualquier color para copiar su código. La paleta H es la que está activa actualmente.

Cómo elegir: usa una base neutral para el 60% del sitio, una superficie para el 25%, un acento para el 10% y reserva el color extra para el 5% (alertas, resultados o detalles premium). Así evitas que la página parezca un semáforo.

Todas las combinaciones mantienen contraste AA en textos principales. La paleta H está aplicada en index.html. Dime la letra que prefieras y la llevo a la página completa.
